📋 Quick Start
Step 1 — Event Setup: Enter your event name and date.
Four on a Court: Upload CSV (Player Name, DUPR ID), auto-assign groups of 4, record 3 rotation matches.
Fixed Partner: Upload CSV (Player 1, DUPR 1, Player 2, DUPR 2), run pool round robins.
Random Shuffle: Upload CSV (Player Name, DUPR ID), set courts & rounds, players shuffle randomly each round.
Manual Entry: Upload CSV (Player Name, DUPR ID), then add each match by selecting 4 players and entering scores.
Export: Each session has its own Export CSV button in the score recording screen.
